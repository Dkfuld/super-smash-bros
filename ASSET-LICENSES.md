pattern, voice line, name, and logo in this project is **original work generated
procedurally in this repository's code** (Canvas 2D DynamicTextures, composed
Babylon geometry, WebAudio synthesis, Speech Synthesis API). No third-party
art, audio, or font files are bundled.

Third-party **code** dependencies (Babylon.js, React, zod, ws, qrcode, Vite,
etc.) are used under their published licenses (Apache-2.0 / MIT) via npm; see
each package's LICENSE in `node_modules` or its repository.

If any external asset is ever added, it must be recorded here with: file path,
source URL, author, license, and verification date — before the PR merges.
